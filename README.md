# mei-facil

# MEI Fácil — Controle Financeiro para Microempreendedores Individuais

> **Projeto Integrado de Extensão — Universidade de Uberaba – UNIUBE**

---

## Sobre o Projeto

O **MEI Fácil** é um sistema web simples e gratuito de gestão financeira desenvolvido para apoiar microempreendedores individuais da comunidade de Uberaba-MG na organização do seu negócio. A solução surgiu de um diagnóstico com 10 empreendedores, onde foi identificado que a maioria controla as finanças de forma manual e enfrenta dificuldades com separação de gastos e uso de tecnologia.

---

## Funcionalidades

- **Registrar Entradas e Saídas** — Cadastre vendas, serviços, compras e despesas
- **Saldo Atual** — Veja de forma imediata quanto tem disponível
- **Resumo Mensal** — Acompanhe entradas, saídas e o resultado (lucro ou prejuízo) de cada mês
- **Contas a Pagar e a Receber** — Não esqueça mais de vencimentos e valores a receber
- **Guia de Uso** — Ajuda simples dentro do próprio sistema

## Sobre o Projeto

Este projeto faz parte do **Projeto Integrado de Extensão** do curso de Sistemas de Informação da Universidade de Uberaba – UNIUBE. O desenvolvimento seguiu as etapas:

| Fase                         | Descrição                                                |
| ---------------------------- | -------------------------------------------------------- |
| **Fase 1 — Diagnóstico**     | Pesquisa com 10 microempreendedores da comunidade        |
| **Fase 2 — Planejamento**    | Definição de funcionalidades, telas e materiais de apoio |
| **Fase 3 — Desenvolvimento** | Codificação do sistema web                               |
| **Fase 4 — Testes**          | Validação com o grupo de empreendedores                  |
| **Fase 5 — Capacitação**     | Encontro presencial com demonstração e prática assistida |
